# Herramientas que Uso

> Also available in [Português](/uses) and [English](/uses/en)

¡Bienvenido a mi página `/uses`, que enumera todas mis herramientas, hardware y software! Como entusiasta y profesional de la tecnología, siempre estoy buscando los mejores equipos y aplicaciones para hacer mi vida más fácil y productiva. Esta página es mi colección seleccionada de las herramientas que uso a diario, organizada por categoría para facilitar la navegación.

**Última actualización**: agosto de 2026

## Trabajo

### 💻 Estación de trabajo

- **Computadora**: Mac Mini 2024 Apple M4, 16GB de RAM, SSD de 256 GB.
- **Periféricos**: Magic Keyboard con Touch ID (USB-C) y Magic Mouse (USB-C).
- **Pantalla externa**: Monitor Dell 27" 4k USB-C p2721q.
- **Webcam**: Logitech C920S Pro HD Webcam.
- **Audio**: Apple AirPods Pro 3 y Edifier W820NB Plus.
- **Hub**: Docking Station UGREEN 11 en 1 con expansión SSD de 2TB.
- **Escritorio**: Husky Standing Desk con superficie personalizada.

### 🧑🏾‍💻 Programación
![Mi editor VSCode](./uses-vscode.png)
- **Editor**: Visual Studio Code con el tema claro predeterminado (porque un verdadero Jedi nunca cae al Lado Oscuro) y un conjunto pequeño, pero útil, de extensiones: [Auto Close Tag](https://marketplace.visualstudio.com/items?itemName=formulahendry.auto-close-tag), [Auto Rename Tag](https://marketplace.visualstudio.com/items?itemName=formulahendry.auto-rename-tag), [Color Highlight](https://marketplace.visualstudio.com/items?itemName=naumovs.color-highlight),  [EditorConfig for VS Code](https://marketplace.visualstudio.com/items?itemName=EditorConfig.EditorConfig), [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint), [Material Icon Theme](https://marketplace.visualstudio.com/items?itemName=PKief.material-icon-theme), [CSV](https://marketplace.visualstudio.com/items?itemName=ReprEng.csv),  [Prettier - Code formatter](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) y [YAML](https://marketplace.visualstudio.com/items?itemName=redhat.vscode-yaml).
- **Terminal**: Terminal nativa de macOS con Oh My Zsh.
- **Stack**: JavaScript, TypeScript, React, React Native, Next.js, NodeJS, MySQL y Postgresql (Supabase).
- **Servicios**: Github, Vercel y Supabase.
